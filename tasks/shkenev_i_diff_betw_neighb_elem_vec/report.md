## 1. Введение

Задача нахождения максимальной разности между соседними элементами вектора является важной при обработке данных и вычислительной математике. Последовательная реализация выполняет линейный проход по массиву, что оптимально по сложности, но при обработке больших данных полезно применять параллельные вычисления. Технология MPI позволяет распределить данные между несколькими процессами и вычислить локальные разности, а затем объединить результаты в один глобальный максимум.

В данной работе реализованы две версии алгоритма:
- Последовательная (SEQ)
- Параллельная (MPI)

Цель работы - реализовать корректное и эффективное параллельное решение и сравнить ускорение.

## 2. Постановка задачи

Дан вектор целых чисел vec[0..N-1].

**Необходимо вычислить:** 
- `max |vec[i+1| - vec[i]|, где 0<=i<N-1`

**Входные данные:**
- Вектор целых чисел InType = std::vector<int>

**Выходные данные:**
- Одно число: максимальная разность между соседними элементами

**Ограничения:**
- Если N < 2, то результат 0
- Данные могут быть любыми

## 3. Базовый алгоритм (последовательный)

Последовательный алгоритм:

```
1. Если N < 2, то вернуть 0
2. max_diff = 0
3. Для i от 0 до N-2:
     diff = abs(vec[i+1] - vec[i])
     если diff > max_diff, то обновить max_diff
4. Вернуть max_diff
```

**Сложность:**
- Время: O(N)
- Память: O(1)

## 4. Схема параллелизации

### Распределение данных

Используется равномерное распределение вектора по блокам:
```
base_size = N / P
remainder = N % P
```
Процессы 0 … remainder−1 получают base_size+1 элементов, остальные - base_size.

Строятся массивы:
```
cnt[i] - количество элементов процесса i
disp[i] - смещение
```

Каждый процесс получает свой блок через:
```
Процесс 0 - memcpy
Остальные - MPI_Recv (точечная коммуникация)
```
### Локальные вычисления

Каждый процесс считает максимум разности внутри своего блока.

### Граничные элементы

**Чтобы корректно сравнить пары, пересекающие границы блоков, применяется обмен:**
- Процесс i+1 получает последний элемент процесса i
- Вычисляет abs(first_of_block - last_of_prev_block)

### Сбор результатов

Для сбора используется:
```
MPI_Reduce(l_max, global_max, MPI_MAX)
MPI_Bcast(global_max)
```

**Анализ результатов:**

1. **1 процесс MPI:** 
- В обоих режимах время значительно больше SEQ (ускорение < 1.0×, эффективность очень низкая)
- Это объясняется накладными расходами MPI (инициализация, коммуникации), которые сильно превышают полезную работу на маленьком векторе

2. **2 процесса:** 
- pipeline: ускорение 0.10x, эффективность 5.2%
- task_run: ускорение 0.18x, эффективность 9.2%
- Добавление второго процесса пока не даёт ускорения, потому что коммуникационные расходы MPI ещё выше, чем выигрыш от распараллеливания

3. **3 процесса:** 
- pipeline: ускорение 0.05x, эффективность 1.8%
- task_run: ускорение 0.26x, эффективность 8.7%
- Производительность падает у pipeline, а у task_run немного повышается, но масштабируемость крайне низкая

4. **4 процесса:** 
- pipeline: ускорение 0.08x, эффективность 2.1%
- task_run: ускорение 0.40x, эффективность 10.0%
- Увеличение числа процессов слегка повышает task_run, но накладные расходы MPI всё ещё преобладают

**Особенности:**

- В текущем тесте SEQ намного быстрее MPI из-за малой нагрузки на каждый процесс и высоких накладных расходов на коммуникации
- task_run показывает более стабильное время при увеличении процессов, чем pipeline
- Масштабируемость крайне низкая — использование более 1 процесса не даёт практического ускорения для таких небольших данных

**Вывод:**

- Для малых векторов MPI неэффективен — накладные расходы превышают выигрыш
- Чтобы увидеть положительный эффект от параллельного выполнения, нужно значительно увеличить размер вектора и работу на каждом элементе
- Оптимизация MPI оправдана только при достаточно большой нагрузке, где полезная работа > накладные расходы

## Приложение

### Фрагменты кода

**Последовательная версия (SEQ):**

```cpp
bool ShkenevIDiffBetwNeighbElemVecSEQ::RunImpl() {
  const std::vector<int> &vec = GetInput();
  int n = vec.size();
  if (n < 2) {
    GetOutput() = 0;
    return true;
  }

  int max_diff = 0;
  for (int i = 0; i < n - 1; i++) {
    int diff = std::abs(vec[i + 1] - vec[i]);
    if (diff > max_diff) {
      max_diff = diff;
    }
  }

  GetOutput() = max_diff;
  return true;
}
```

**Параллельная версия (MPI):**

```cpp
bool ShkenevIDiffBetwNeighbElemVecMPI::RunImpl() {
  int world_rank, world_size;
  MPI_Comm_rank(MPI_COMM_WORLD, &world_rank);
  MPI_Comm_size(MPI_COMM_WORLD, &world_size);

  const std::vector<int> &vec = GetInput();
  int n = vec.size();

  if (n < 2) {
    GetOutput() = 0;
    return true;
  }

  if (world_size > n) {
    int result = 0;
    if (world_rank == 0) {
      for (int i = 0; i < n - 1; ++i) {
        int diff = std::abs(vec[i + 1] - vec[i]);
        if (diff > result) {
          result = diff;
        }
      }
    }
    MPI_Bcast(&result, 1, MPI_INT, 0, MPI_COMM_WORLD);
    GetOutput() = result;
    return true;
  }

  int base_size = n / world_size;
  int remainder = n % world_size;

  std::vector<int> cnt(world_size);
  std::vector<int> disp(world_size);
  int shift = 0;
  for (int i = 0; i < world_size; ++i) {
    cnt[i] = base_size;
    if (i < remainder) {
      cnt[i] = base_size + 1;
    }
    disp[i] = shift;
    shift += cnt[i];
  }

  int l_n = cnt[world_rank];
  std::vector<int> l_vec(l_n);

  if (world_rank == 0) {
    if (l_n > 0) {
      std::copy(vec.begin(), vec.begin() + l_n, l_vec.begin());
    }

    for (int p = 1; p < world_size; ++p) {
      if (cnt[p] > 0) {
        MPI_Send(vec.data() + disp[p], cnt[p], MPI_INT, p, 0, MPI_COMM_WORLD);
      }
    }
  } else {
    if (l_n > 0) {
      MPI_Recv(l_vec.data(), l_n, MPI_INT, 0, 0, MPI_COMM_WORLD, MPI_STATUS_IGNORE);
    }
  }

  int l_max = 0;
  for (int i = 0; i < l_n - 1; ++i) {
    int diff = std::abs(l_vec[i + 1] - l_vec[i]);
    if (diff > l_max) {
      l_max = diff;
    }
  }

  if (world_size > 1) {
    if (world_rank > 0 && l_n > 0) {
      int prev_last = 0;
      MPI_Recv(&prev_last, 1, MPI_INT, world_rank - 1, 1, MPI_COMM_WORLD, MPI_STATUS_IGNORE);

      int boundary_diff = std::abs(l_vec[0] - prev_last);
      if (boundary_diff > l_max) {
        l_max = boundary_diff;
      }
    }

    if (world_rank < world_size - 1 && l_n > 0) {
      int my_last = l_vec[l_n - 1];
      MPI_Send(&my_last, 1, MPI_INT, world_rank + 1, 1, MPI_COMM_WORLD);
    }
  }

  int global_max = 0;
  MPI_Reduce(&l_max, &global_max, 1, MPI_INT, MPI_MAX, 0, MPI_COMM_WORLD);
  MPI_Bcast(&global_max, 1, MPI_INT, 0, MPI_COMM_WORLD);

  GetOutput() = global_max;

  return true;
}
```
